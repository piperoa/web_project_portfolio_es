# Portafolio

## Descripción

Este proyecto es un sitio web de portafolio personal desarrollado como parte del Sprint 4 de TripleTen.

La página incluye una presentación personal, una sección de habilidades, proyectos destacados y enlaces de contacto. El objetivo del proyecto fue practicar diseño responsivo utilizando HTML y CSS siguiendo un diseño en Figma.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- Grid Layout
- Media Queries
- Metodología BEM
- Normalize.css

## Características

- Diseño responsivo
- Efectos hover interactivos
- Overlay con gradientes
- Imágenes adaptativas
- Diseño moderno inspirado en Figma
- Estructura semántica HTML
